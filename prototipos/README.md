# Protótipos

Esta pasta contém os wireframes e protótipos das principais telas do projeto NORTH.

## Conteúdo

Os protótipos poderão incluir:

- Tela de login;
- Tela inicial;
- Tela de atividades;
- Tela de nova atividade;
- Tela de detalhes da atividade;
- Tela de meta.

## Ferramenta

Os protótipos serão desenvolvidos no Figma.

O link do protótipo será adicionado nesta pasta quando estiver disponível.
