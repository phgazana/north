# Testes

Esta pasta contém os artefatos relacionados à validação e aos testes do projeto NORTH.

## Conteúdo

Os materiais poderão incluir:

- Plano de testes;
- Casos de teste;
- Evidências de execução;
- Resultados obtidos;
- Registro de erros encontrados;
- Correções realizadas.

## Objetivo

Garantir que as principais funcionalidades do sistema atendam aos requisitos definidos e funcionem conforme o esperado.
