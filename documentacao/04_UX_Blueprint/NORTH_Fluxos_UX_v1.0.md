# NORTH — Fluxos UX v1.0

## Fluxo 01 — Primeiro acesso
Boas-vindas → Cadastro → Onboarding curto → Meta opcional → Primeira atividade → Home.

## Fluxo 02 — Uso diário
Home → Criar atividade → Planejamento opcional → Projeção atualizada → Detalhe → Concluir → Registrar realidade → Resultado/Projeção recalculados.

## Fluxo 03 — Ciclo de vida da Atividade
PENDENTE → CONCLUÍDA ou CANCELADA.
CONCLUÍDA → PENDENTE por reabertura.
CANCELADA → PENDENTE por reabertura.
Qualquer estado pode ser movido para Lixeira e, dentro da retenção, restaurado ao estado anterior.
Duplicar cria uma nova atividade independente e PENDENTE.

## Fluxo 04 — Direção mensal
Home → Gerenciar Meta → Home recalculada → Virada do mês → Novo ciclo independente → Histórico → Detalhe do mês.

## Fluxo 05 — Comportamentos transversais
Navegação → Busca contextual → Estados vazios → Validações → Erros → Conectividade → Conta / Logout / Exclusão de conta.

## Hierarquia da Home
1. Projeção
2. Resultado atual
3. Meta
4. Distância para meta
5. Entradas/Saídas realizadas e previstas
6. Atividades relevantes

## Regras de comunicação
- Não usar “saldo” para representar o resultado do NORTH.
- Não usar linguagem punitiva sobre gastos, atrasos ou metas.
- Não mostrar R$ 0,00 quando o valor é desconhecido.
- Explicar quando a projeção usa apenas valores conhecidos.
