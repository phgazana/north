# Apresentação

Esta pasta contém os materiais utilizados nas apresentações acadêmicas do projeto NORTH.

## Conteúdo

Os materiais poderão incluir:

- Apresentações em slides;
- Roteiros de apresentação;
- Imagens e diagramas utilizados;
- Materiais de apoio;
- Versões finais apresentadas à disciplina.

## Objetivo

Centralizar os arquivos utilizados para demonstrar a evolução, os resultados e as entregas do projeto NORTH.
