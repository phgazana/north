# Banco de Dados

Esta pasta contém os artefatos relacionados à modelagem e implementação do banco de dados do projeto NORTH.

## Estrutura

- `modelo/` — modelos e diagramas do banco de dados, incluindo Modelo E/R e modelo físico.
- `scripts/` — scripts SQL utilizados para criação, alteração e carga de dados do banco.

## Tecnologia

O banco de dados definido para o projeto é PostgreSQL.
